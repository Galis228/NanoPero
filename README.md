# Релизы НаноПеро

Эта ветка хранит только последнюю версию приложения:

- `NanoPero.apk` — установочный файл (Android, arm64);
- `latest.json` — номер версии и список изменений. По нему приложение проверяет обновления.

Скачать: [NanoPero.apk](https://raw.githubusercontent.com/Galis228/NanoPero/releases/NanoPero.apk)
